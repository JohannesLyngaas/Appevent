# 📂 src Folder Structure

## 📁 app
Inneholder sider og ruter for Next.js App Router. Hver mappe representerer en rute, med `page.tsx` for innhold og `layout.tsx` for sideoppsett.

## 📁 components
Gjenbrukbare UI-komponenter som knapper, navigasjonsbarer, kort, osv.

## 📁 hooks
Egendefinerte React-hooks for logikk som kan gjenbrukes, f.eks. `useAuth`, `useFetch`, osv.

## 📁 lib
Verktøyfunksjoner og API-kall. Kan inkludere konfigurasjonsfiler eller tredjepartsintegrasjoner.

## 📁 styles
Globale og modulspesifikke CSS- eller Tailwind-filer, f.eks. `globals.css`.

## 📁 utils
Hjelpefunksjoner som håndterer databehandling, validering eller formattering.
