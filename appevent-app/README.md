## Hvordan du kan kjøre development server
Sørg for at du har følgende installert:
- Node.js 18.18 eller nyere

Terminal kommandoer for å kjøre development server (få opp nettsiden):
```bash
# 1. Kjør først:
npm install

# 2. Kjør deretter:
npm run dev

```

Åpne deretter [http://localhost:3000](http://localhost:3000) på din browser for å se web-applikasjonen.
